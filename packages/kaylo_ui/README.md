# kaylo_ui

The Kaylo look, shared by the customer and partner apps:

- `theme/`: colors, spacing, radius, shadows, typography, and `AppTheme` (light, dark and the high-contrast care theme).
- `widgets/`: buttons, cards, chips, liquid glass, loader and logo, snackbar, text field, price tag, rating stars, search field, section header, service tile, worker card, shimmer, the confirmation tick.

Import with `package:kaylo_ui/kaylo_ui.dart`.

Rules: widgets here take any user-facing text as parameters; localized strings belong to the app that shows them. This package depends on `kaylo_core` only.
