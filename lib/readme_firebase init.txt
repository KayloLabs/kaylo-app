# Firebase Authentication Service

A clean, production-ready Dart helper wrapper for managing user registration, logins, and sessions via **Firebase Authentication** in Flutter.

## 🚀 Getting Started

### 1. Prerequisites
Before using this service, ensure you have initialized Firebase globally in your project. If you haven't already, run the configuration tool:
```bash
flutterfire configure
```

### 2. Initialization
You **must** initialize Firebase in your `lib/main.dart` before calling any authentication functions. Add the following setup to your `main()` function:

```dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart'; // Auto-generated by FlutterFire CLI

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  runApp(const MyApp());
}
```

---

## 🛠️ Service Architecture

This service acts as a middleman between your UI layer and the Firebase SDK using a single backend engine connection (`FirebaseAuth.instance`).

### Available Functions

| Function | Parameters | Description |
| :--- | :--- | :--- |
| `signUp(email, password)` | `String`, `String` | Registers a brand-new user database entry. |
| `signIn(email, password)` | `String`, `String` | Authenticates an existing user and creates an active session. |
| `signOut()` | *None* | Terminates the active session and logs the user out. |

## 💻 Usage Example

Import the service file into your UI view layer (e.g., `login_page.dart`) to bind authentication actions to button workflows:

```dart
import 'package:flutter/material.dart';
// Replace with the relative path to your auth service file
import 'package:kaylo_app/services/auth_service.dart'; 

class LoginPage extends StatelessWidget {
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();

  LoginPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Column(
        children: [
          TextField(controller: _emailController, decoration: const InputDecoration(labelText: 'Email')),
          TextField(controller: _passwordController, decoration: const InputDecoration(labelText: 'Password'), obscureText: true),
          
          ElevatedButton(
            onPressed: () async {
              // Call the wrapper service function safely
              await signIn(_emailController.text.trim(), _passwordController.text.trim());
            },
            child: const Text("Sign In"),
          ),
        ],
      ),
    );
  }
}
```

## ⚠️ Error Handling
The functions are wrapped inside `try-on FirebaseAuthException` blocks. 
* Errors (such as `weak-password`, `email-already-in-use`, or `invalid-credential`) will currently output straight to the developer debug console via `print()`.
* **Future Upgrade:** Consider modifying the functions to return a `String?` error message or `UserCredential` instead of `void` to pass exception states directly back to your UI layers.
